# Weather_Tracker

A Python web application that fetches real time weather date of cites in a database.
## features
- Fetches weather data from Open-Metro API
- Stores the data in PostgresSQL database
- Displays all

## Installation
- PostgreSQL
- PGAdmin
- Git
#### Required software
- python **3.13.7**
- Postgres

#### Python packages
- requests
- pyscogp
